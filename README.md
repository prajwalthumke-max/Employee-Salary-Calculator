# Employee Salary Calculator

## About the Project

The Employee Salary Calculator is a simple Java console application that calculates employee salaries based on basic salary, allowances, and tax deductions.

## Features

- Accepts employee ID and name.
- Calculates House Rent Allowance (HRA).
- Calculates Dearness Allowance (DA).
- Calculates tax deductions.
- Calculates net salary.
- Displays the average salary and highest-paid employee.

## Technologies Used

- Java
- Scanner class
- Loops and conditional statements
- Basic arithmetic operations

## Salary Calculation

- HRA = 20% of basic salary
- DA = 10% of basic salary
- Tax = 5% of basic salary
- Net Salary = Basic Salary + HRA + DA - Tax

## How to Run

1. Install the Java JDK.

2. Save the source code as `Main.java` and ensure the public class is named `Main`.

3. Open the terminal in the project folder.

4. Compile the program:

   `javac Main.java`

5. Run the program:

   `java Main`

## Learning Outcomes

This project helps demonstrate Java input handling, loops, calculations, and basic data processing.
